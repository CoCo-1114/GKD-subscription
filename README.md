# GKD 广告跳过订阅

针对个人应用清单整理的 GKD 广告规则，包含开屏、弹窗、悬浮和信息流等场景。

## 订阅地址

复制以下链接，在 GKD 的订阅页面点击 `+` 添加：

```text
https://raw.githubusercontent.com/CoCo-1114/GKD-subscription/main/gkd.json5
```

## 当前内容

- 26 个应用的专用规则，共 98 组、207 条。
- 另有 1 组、2 条限定应用白名单的通用开屏规则。
- 默认开启 19 组专用开屏规则，其他广告组默认关闭，可按需启用。
- 订阅 ID：`2026110702`，版本：`3`。
- 订阅文件已去除作者、来源/更新链接、快照及运行示例参考字段。

已通过选择器语法、类型、依赖和应用白名单检查。尚未进行手机实测，不能保证适用于当前所有应用版本。

## 更新

本仓库发布整理后的静态文件，不自动同步上游。后续更新沿用相同订阅 ID 并增加版本号，再替换 `gkd.json5`；GKD 可通过原订阅地址获取更新。
